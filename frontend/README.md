# 前端

浏览器客户端使用 React、TypeScript、Vite 和 CSS。注册、登录、建立会话、发送和查询消息使用 HTTP。普通 JSON 接口统一返回 HTTP `200`，前端读取响应体中的 `code`、`msg` 和 `data` 判断业务结果。WebSocket 接收新消息通知，握手成功返回 `101`，票据失效返回 `401`，同源校验失败返回 `403`。

[Docker Compose 方式](../docker/README.md)会构建前端并通过 Nginx 提供页面，默认端口为 8081。开发页面时可使用下面的 Vite 命令。

## 本地运行

按[后端 README](../backend/README.md#启动服务)初始化 MySQL 并启动 Gin。使用 Node.js 20.19 或 22.12 及以上的受支持版本，在本目录执行：

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。Vite 将 `/api` 和 `/ws` 转发到 `http://127.0.0.1:8080`。如果后端使用了其他地址，可以给 Vite 设置 `IM_FRONTEND_BACKEND`。本地构建运行 `npm run build`，构建预览运行 `npm run preview`。部署时，通过同一个站点提供静态文件，并转发 `/api` 和 `/ws` 到 Gin。

## 双账号演示

1. 在两个独立浏览器会话注册账号。在「我的」查看自己的用户名或退出登录。
2. 在「通讯录 → 好友」输入对方的完整用户名，查找到昵称后发送申请；对方在「通讯录 → 好友申请」查看并同意。页面打开后可点击「刷新」查询新的申请或好友。
3. 从好友列表选择「发消息」，双方的会话列表和聊天标题都会显示对方昵称。输入消息后按 Enter 发送，按 Shift + Enter 换行。向上滚动或选择「加载更早消息」，可以查看历史。
4. 让接收方断开网络，发送几条消息，再恢复网络。接收端重新申请票据，并使用 `after_seq` 补齐消息。
5. 在好友列表确认解除好友后，仍可从「会话」打开已有聊天记录；重新成为好友后可以在原会话继续发送消息。

会话列表显示最新消息预览，并在每条会话右下角显示其他成员发来的未读消息数。打开会话后，页面可见且阅读位置在底部时，客户端上报已连续显示的最大消息序号；查看较早记录或将标签页切换到后台时保留未读提醒。刷新列表可取得同一账号在其他设备更新的已读进度。聊天页面不显示对方的已读回执。

桌面采用图标导航、会话列表和聊天区域三栏布局。小屏幕将导航移到底部，打开聊天后可用标题栏的返回按钮回到会话列表。会话搜索可按好友昵称、群名和最新消息筛选当前列表。搜索框旁的加号可打开创建群聊和查找好友的入口。

## 群聊操作

1. 在「会话 → 加号 → 创建群聊」填写群名，可以从好友中选人。群聊最多 200 人。
2. 打开群聊后，可以查看群成员发送的文本和昵称。群消息沿用会话预览、未读数和断线同步。
3. 点击聊天标题栏的「群详情」查看成员和角色。群主可以改名、设置管理员及转让群主身份。群主和管理员可以邀请自己的好友，管理员可以移除普通成员。
4. 退出或被移除后，会话从列表移除。再次加入后，聊天页面从本次加入的位置开始显示消息。

## 会话摘要同步

- 收到连续消息时直接更新会话预览和未读数，发送者自己的消息和重复推送不增加未读。
- 消息序号出现缺口、群信息或成员变化时，合并查询受影响的会话。前台定期检查会话序号和已读进度，发现未收到的通知时查询对应会话。
- 同一账号的其他设备更新已读后，同步进度会推进；缺少统计所需的消息时读取服务端未读数。
- 使用 Node.js 24 运行 `node --test frontend/tests/conversation-summary.test.mjs` 验证缺口、重复消息和已读更新。

## 聊天图片

- 点击输入栏的「图片」，或直接粘贴复制的图片、截图。预览可以移除或替换，支持 JPEG、PNG、WebP，单张最多 5 MiB。
- 有待发送图片时，Enter 一并发送图片和输入栏文字；点击聊天图片查看原图。图文与文字共用消息发送接口。粘贴网址仍按文字输入。

## 头像和在线状态

- 「我的 → 更换头像」支持上传 JPEG、PNG 或 WebP 图片，文件上限为 2 MiB。
- 好友列表、好友单聊会话列表和聊天标题显示在线状态。任一设备保持 WebSocket 连接时显示在线。

## 积分和红包

- 「我的 → 积分」显示可用余额、初始发放、红包扣减、领取增加和退款记录。
- 在单聊或群聊点击「发红包」。群聊可设置份数，确认前会显示总积分。
- 点击聊天里的红包卡片查看领取状态。领取成功后，会话里会新增领取提示；单聊发送者看到对方领取的提示，群聊成员看到领取者昵称。红包领完后卡片颜色变淡。有效期为 24 小时，未领取的积分会在到期后退回。

登录凭证保存在标签页的 `sessionStorage`，退出登录或凭证过期时清除。消息与同步进度保存在当前页面的内存中，刷新页面后打开会话会重新加载最近一页。消息 ID 和序号保持为十进制字符串，序号运算使用 `BigInt`。
